# Dev Ahmad Mohammad Portfolio

Modern bilingual portfolio built with React + TypeScript + Vite.

## Local development

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Create a repository named:
   `AhmadElastal.github.io`
2. Upload this project to the repository.
3. Make sure the default branch is `main`.
4. Open:
   `Settings → Pages`
5. Under **Build and deployment**, choose:
   `GitHub Actions`
6. Push any change to `main`.

Your site will be available at:

`https://AhmadElastal.github.io`

## Notes

- Arabic / English switching is built in.
- RTL / LTR direction changes automatically.
- WhatsApp and email links are already configured.
- Current project cards are stored in `src/App.tsx`.
- A real admin dashboard requires a backend service such as Supabase and is intentionally not included yet.
